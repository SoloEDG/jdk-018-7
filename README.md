# GLYPH ASCII Studio

安装：`npm ci`

本地启动：`npm run dev`

类型检查：`npm run typecheck`
构建：`npm run build`

Docker 启动：`docker compose up --build`，访问 http://localhost:18018。

## 多版本配准对照

在「版本配准对照」标签页中：

- **冻结版本**：把当前作品（来源缩略图、裁剪、旋转、字符参数、字符网格）深拷贝为独立快照。
  版本不持有当前作品的任何引用，之后调整参数、释放原图资源都不会令冻结版本重算或串位。
- **锚点配准**：在两版来源缩略图的同一特征处按相同顺序打点（至少 3 对、不可近共线）。
  系统用最小二乘求解 from→to 仿射变换，锚点对不足、近共线、矩阵奇异或 RMSE 超限时，
  保留上次有效对齐并明确提示问题，配准变换只服务对照视图，不会重排任何版本冻结的字符。
- **两种比较**：
  - 屏幕效果比较：以基准版展示坐标为平面，叠加两版实际字符效果；
  - 来源位置比较：以基准版原图自然方向坐标为平面，按来源位置对齐。
  两种模式都可显示各自的不重叠区（斜线填充），避免缩放后误判为逐格一致。
- **恢复与导出**：任一冻结版本可原子恢复为当前作品（恢复失败时当前作品不变）；
  可导出带配准标尺的对照页 PNG，或导出该版独立结果（PNG 可选标尺 / TXT）。
- **身份隔离**：对齐缓存、问题状态、对照偏好与单版导出选择均按版本 ID 存储，
  删除版本只清理其专有缓存，其余版本的对齐依据与导出选择不受影响。
